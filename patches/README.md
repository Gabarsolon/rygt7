# Bundled GT7 Offline mode patch

`CUSA24769.xml` is the `Offline mode` group of Proper Offline Patch v1.0's
ps-patch-system patch definitions, unmodified, provided with releases so **Set up** can
apply the dealership fix without a separate download or manual copy. The upstream
file's other groups (DLC unlocks, store rotation, debug settings) are not included.
The existing executable compatibility check still applies.

Source: https://github.com/jimnastic89/gt7patcher/blob/e49e2db1fed54fb7b46a666a1c889d821c5903af/xmlpatches/CUSA24769.xml

The accompanying `Proper-Offline-Patch-README.txt` retains the upstream
documentation and credits. Its console installation instructions do not
apply to RyGT7: use the launcher's **Set up**, then **Play**.

The upstream patch definitions were AI-generated and released without author
attribution. They build on the offline-patch work of High-Speed007 and
PSVIETHOA, with testing credited to Dr.Yenyen. The upstream third-party
notices state that no explicit software license or redistribution terms
accompanied the patch XML; RyGT7 does not assign its own license to this file.
