Gran Turismo 7 setup

  1. Extract the complete ryGT7 release to a writable folder, separate from your game folders.
  2. Run RyGT7.exe.
  3. Select your decrypted Gran Turismo 7 base game, CUSA24769. Pick the folder containing eboot.bin, sce_sys/param.sfo, sce_module, and contents with gt.idx and the gt*.vol archives.
  4. If your update is already merged into that folder, leave Update empty. Otherwise select the extracted update folder containing its own eboot.bin and sce_sys/param.sfo.
  5. Select your PS4 firmware's system modules and the fonts folder containing font and font2.
  6. Press Set up. Once it finishes, press Play, then choose Online or Offline.

Keep your game and update folders in place after setup: their files are linked, not copied. Use the same drive as your game dump, or turn on Windows Developer Mode to link across drives. Your source game files are never patched.

Gran Turismo Sport setup

RyGTS runs Gran Turismo Sport (CUSA03220, update 1.69) as a native Windows program.

  1. Download the latest RyGTS release.
  2. Dump these from your own PS4: GT Sport CUSA03220 decrypted with update 1.69, plus the system modules and fonts. They aren't provided here.
  3. Unzip the release on the same drive as your dump.
  4. Run RyGT.exe, then pick your game, update, firmware module and font folders.
  5. Press Set up, then Play.

GT7 docs

What Set up checks

It rejects other title IDs, malformed metadata, incomplete folders, and updates older than the selected game. It converts into a staging folder first, so a failed conversion keeps your existing executable. When it replaces app0, the old folder is kept as app0.previous-<timestamp>. Your dumps and saves are left alone.

Verified game version

The verified dump is CUSA24769 with APP_VER 01.00. Separate updates are tested, but later game updates have not been verified for conversion or gameplay.

Offline mode patch

Releases include the community Offline mode patch as patches\CUSA24769.xml, and Set up applies it automatically. Only its Offline mode group is used, never DLC unlocks or debug settings. If the file is added, changed or removed later, Play runs Set up again. The game writes its dealership catalog to data\gt7offline.

Settings and where files live

Display, FSR/DLSS, shader compilation, logging, controller bindings, ports and wheel settings are in the launcher. Paths are stored in RyGT7.ini. Logs, shaders, converted output and saves stay in the launcher folder.

Updates

The launcher checks GitLab for the newest release at start. If there is one, an Update button appears at the top right of the home page. It verifies the download, moves replaced files to update\backup-<old version>, and restarts. Your user\ folder, shaders, converted game and .ini files are not touched. You can turn the check off or roll back in Settings > Display.

Building from source

Run build.cmd <output-folder> from a Windows command prompt. It uses the C# compiler included with .NET Framework. Run test-gt7.cmd <temporary-output-folder> for setup regression checks.

What releases contain

Releases include the open-source converter, GT7 runtime libraries, renderer and their dependencies. Players provide all game files, firmware modules and fonts. No game, firmware, saves or game shader packs are in a release. The launcher is GPL-2.0-only.

FAQ

These answers are for GT7. GT Sport online is still in development.

How do I join a server?

On the Online page, press Find servers, then Join next to a server. The launcher signs you in and starts the game.

How do I host?

Press Start hosting on the Online page. Friends outside your home need these ports forwarded to your PC: 7890 TCP and UDP, 31313 TCP, 31315 TCP, and 3658 TCP and UDP. Then press Allow through firewall.

Does my save stay on my PC?

Yes. A host only keeps your account and online session data.

Can I play without going online?

Yes. Press Play, then Offline. You don't need an account or a server.

Why is another player's car jumping around?

This is a known problem we're still measuring. A slow PC or an unstable connection on either side can cause it.

Known issues (GT7)
